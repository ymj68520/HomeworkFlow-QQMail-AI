## 使用指南

### 1. 快速检测（查看当前状态）
```bash
python scripts/quick_detect_multi_assignment.py
```

### 2. 测试模式（不修改数据库）
```bash
# 处理 3 条记录
python scripts/redetect_multi_assignment.py --dry-run --limit 3
```

### 3. 实际处理（修改数据库）
```bash
# 处理所有没有 group_id 的记录
python scripts/redetect_multi_assignment.py

# 只处理少量记录
python scripts/redetect_multi_assignment.py --limit 10
```

### 4. 强制重新处理所有记录
```bash
python scripts/redetect_multi_assignment.py --force
```
